# 宝石あつめ ストーリー設定書

周回（プレステージ）するたびに、お屋敷の謎が少しずつ解けていく物語です。
**初回プレイ＋5回のプレステージ＝全6夜**で、ひとつの物語が完結します。

> この文書はまだゲームに組み込んでいません。「こういう話にする」という設計図です。
> 名前・セリフは自由に書きかえてください（とくに人物名は仮のものです）。

---

## 1. 物語のしくみ（ひとことで）

**一度の周回＝お屋敷での一晩。プレイヤーは毎晩ここに来ていて、毎晩忘れている。**

夜が明けないお屋敷で、おじょうさまと宝石を集める。
朝が来ないまま夜がまた始まり、おじょうさまは毎回「はじめまして」と言う。
プレイヤーだけが、それを覚えている。

### 3つの大きな謎

| | 謎 | 答え | 明かす夜 |
| --- | --- | --- | --- |
| 一 | なぜ夜が明けないのか | 「朝」を覚えている人が、もう誰もいないから | 六夜目 |
| 二 | 宝石とは何なのか | このお屋敷を訪れた人の**記憶** | 四夜目 |
| 三 | おじょうさまは何者なのか | 屋敷の主ではなく、**いちばん最初のお客様** | 五夜目 |

### いちばん大事な仕掛け

プレステージすると、宝石もレベルもゼロに戻ります。でも**「見る目」だけは残ります**
（＝プレステージボーナス）。

これに物語の意味をつけます。

> 記憶は毎晩お屋敷に取られる。でも、**見る目だけは取られない**。
> だから周回するほど、集めた記憶は消えるのに、宝石を見つける腕だけが上がっていく。

`Hades` の作り手が語っている設計そのものです。ローグライクでリセットされても
プレイヤーの「知識」だけは残る → ならば**その知識を持ち越せる人物とは誰か**を考える。
このゲームの答えが「記憶は失うが、目は覚えている客」です。

## 2. 登場人物

### おじょうさま（仮名：アウロラ）
森のお屋敷にひとりで住む、黒い服の少女。上品で、ていねいで、少し人恋しい。
自分の名前を思い出せない。「おじょうさま」は客が勝手にそう呼んだだけの呼び名。

- 口調：「〜ですわ」「ごきげんよう」「〜かしら」
- 毎晩、集まった宝石をひとつずつ磨いている
- **正体**：このお屋敷に最初に迷い込んだ客。帰り道を忘れて、そのまま住人になった

> 名前の「アウロラ」は**夜明け**という意味の言葉から取っています。
> 彼女は自分が失くしたものを名前にしている、という仕掛けです。気に入らなければ変更OK。

### あなた（プレイヤー）
名前は出てきません。来客帳に何度も書かれている、常連のお客様。

### お屋敷（森）
人物として出てきませんが、**このお話の本当の主**です。
訪れた人から記憶を少しずつ取り、それが宝石になって夜の森に落ちてきます。
宝箱（エレガントタイム）は、客を引き止めておくための贈り物。

## 3. ゲームのしくみと物語の対応表

既にあるしくみに、あとから意味をつけています。**新しく作るものはほとんどありません。**

| ゲームのしくみ | 物語での意味 |
| --- | --- |
| 夜に宝石が湧いてくる | 森が、客から取った記憶を落としている |
| タップして集める | 記憶をひろい集めている |
| おじょうさまが磨く | 持ち主に返せるように、きれいにしている |
| **形**レベル（見える形が増える） | **見る目が育つ**。宝石は前からそこにあった。見えなかっただけ |
| **色**レベル | 記憶の種類（うれしい・さみしい・なつかしい） |
| **大きさ**レベル | 大きい宝石＝その人の、大事な一日 |
| 王冠型（形Lv20） | 「お屋敷の主のしるし」。彼女が主だと思われてきた理由 |
| **花型（形Lv30）** | **おじょうさまが落とした「朝」の記憶**。最終話の鍵 |
| 宝箱／エレガントタイム | お屋敷から客への贈り物。機嫌を取って、客を引き止めている |
| プレステージ（周回） | 夜が終わり、また同じ夜が始まる。記憶＝宝石は取られる |
| プレステージボーナス | **見る目**。記憶は消えても、目だけは覚えている |

| プレステージすること | **夜をかさねる** |

## 5. 各夜の台本

各夜は3つの部品でできています。

- **冒頭ADV** … 夜のはじまりに出す全画面の会話（今の会話画面）
- **プレイ中のコメント** … 遊んでいる最中に、じゃまをせず出る短いひとこと
- **夜の終わり** … プレステージボタンを押したときに出す全画面の会話

## 6. 見せ方の設計（調べたうえでの結論）

**「別画面で読ませる」か「プレイ中のコメント」かは、選ばなくていいです。**
役割がちがうので、3つとも使って、それぞれに違う仕事をさせるのが定石です。

| 見せ方 | 担当させるもの | なぜ |
| --- | --- | --- |
| **全画面の会話（今作ったADV）** | 夜のはじまりと終わり（＝周回の変わり目） | プレステージ直後は、プレイヤーが唯一ちゃんと画面を見ている瞬間。全画面で止めても許されるのはここだけ |
| **プレイ中のコメント** | 物語の小出し。8割はここ | 放置ゲームは「ながら見」。目線の先に出る短文がいちばん届く |
| **ストーリー画面** | 読み返すための保管場所 | 流れるコメントは必ず見逃される。あとから全部読めるようにする |

### 事例

- **Hades**：死んで戻るたびに登場人物が新しいことを言う。作り手いわく、出発点は
  「ローグライクでリセットされても、プレイヤーの知識だけは残る。ならば、それを
  地で行く人物とは？」という問い。**周回をキャラクターに認識させること**が核心。
- **Cookie Clicker**：世界観の供給源はほぼ画面上部のニュースティッカー。10秒ごとに
  勝手に流れ、プレイの手を止めない。物語専用の画面は存在しない。
- **A Dark Room / Universal Paperclips**：専用の物語画面を持たず、進行そのものが物語。
- **Loop Hero**：走行中は短い会話、拠点（キャンプ）で腰を据えた会話、と役割分担。
  ただしレビューでは「物語はゲームループの乗り物どまり」とも評されていて、
  **深い話を拠点側に置くだけでは足りない**ことも示している。

### このゲームへの具体的な注意

1. **宝石100個でストーリー解放、はやめたほうがいい。**
   物語は「進んだから読める」であるべきです。自分の物語を通貨で買わせると、
   多くの人はスキップします。**〇夜目に到達したら解放**に変える。
2. **プレイ中のコメントに「OK」ボタンを付けない。** いまのチュートリアル吹き出しは
   プレイを止めるタイプなので、ストーリー用は**止めない版**を別に作ること。
   数秒で自動的に消える形が良い。
3. **同じセリフをわざと繰り返す。** 二夜目で「はじめまして」と言われる違和感が、
   このゲームの最大の武器です。使い回しは手抜きではなく、演出です。
4. **既読スキップを必ず付ける。** 周回ゲームは同じ画面を何度も通ります。
5. **コメントは1〜2行まで。** 長い話は全画面ADVに回す。

### おすすめの実装順（組み込むとき）

1. プレイ中のコメント機能（止まらない吹き出し）を作る ← これが土台
2. 各夜の冒頭ADVと締めADVを、プレステージ機能につなぐ
3. ストーリー画面を「読み返し」に作りかえる（〇夜目で自動解放）
4. 二夜目のセリフ使い回しを実装して、違和感の演出を確認する
