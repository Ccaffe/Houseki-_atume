# 宝石あつめ 💎

宝石をクリック(タップ)して集めるクリッカーゲームです。

## 遊び方

1. `index.html` をブラウザで開く
2. 画面のあちこちに宝石が2〜3個出現します
3. 宝石をクリック(タップ)すると、キラーン♪という効果音と共に消えて集まります
4. 「Lv UP」ボタンで、集めた宝石を使って強化ができます
   - **大きさ** … 宝石が大きくなってタップしやすくなる
   - **形** … 1個で集まる宝石の数が増える
   - **色** … 虹色のレア宝石(5倍!)が出やすくなる
5. 「せってい」から、集めた宝石の総数などの統計が見られます
6. データはブラウザに自動保存されるので、閉じてもまた続きから遊べます

## ファイルの説明

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の**構造**(何がどこにあるか)を書くファイル |
| `style.css` | 画面の**見た目**(色・大きさ・配置)を書くファイル |
| `script.js` | ゲームの**動き**(クリックしたら宝石が増える等)を書くファイル |

どのファイルにも日本語のコメント(`<!-- -->` や `/* */` や `//` で囲まれたメモ)を
たくさん書いてあるので、読みながら少しずつ変更してみてください。

## VS Code での編集のしかた

1. VS Code を開く
2. メニューの「ファイル」→「フォルダーを開く」で、このフォルダーを選ぶ
3. 左側のファイル一覧から編集したいファイルをクリックして開く
4. 保存は `Ctrl + S`(Mac は `Cmd + S`)

### 動かして確認する方法(おすすめ)

VS Code の拡張機能 **Live Server** を入れると便利です。

1. VS Code の左側の四角いアイコン(拡張機能)をクリック
2. 「Live Server」で検索してインストール
3. `index.html` を右クリック →「Open with Live Server」
4. ブラウザが開いてゲームが動きます。**ファイルを保存すると自動で画面が更新される**ので、
   変更した結果がすぐ確認できます

拡張機能を入れなくても、`index.html` をダブルクリックしてブラウザで開くだけでも動きます。

## 宝石を自分の画像に差し替えたいとき

今の宝石は `index.html` の中の `<template id="gem-template">` にある
`<svg>` タグ(図形を描くタグ)で描いていて、これが宝石の「型紙」になっています。
自分で用意した画像を使いたいときは:

1. 画像ファイル(例: `gem.png`)をこのフォルダーに入れる
2. `<template id="gem-template">` の中の `<svg> ... </svg>` を丸ごと消して、
   代わりにこう書く:

   ```html
   <img src="gem.png" alt="宝石" style="width: 100%;">
   ```
