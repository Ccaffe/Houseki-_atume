# 宝石あつめ 💎

宝石をクリック(タップ)して集めるクリッカーゲームです。

## 遊び方

1. `index.html` をブラウザで開く
2. 画面のあちこちに宝石が2〜3個出現します
3. 宝石をクリック(タップ)すると、キラーン♪という効果音と共に消えて集まります
4. 「Lv UP」ボタンで、集めた宝石を使って強化ができます(下の「レベルアップの効果と点数」を見てね)
5. 「せってい」から、集めた宝石の総数などの統計が見られます
6. データはブラウザに自動保存されるので、閉じてもまた続きから遊べます

## レベルアップの効果と点数

**1タップで集まる宝石の数 = 形Lv +(大きさLv − 1)**
虹色のレア宝石なら、さらに **×5倍**!

| 強化 | レベルが上がると何が起きる? |
|---|---|
| **大きさ** | 1タップの獲得数が **+1** ずつ増える。宝石の見た目も1レベルごとに **+5ピクセル** ずつ少しずつ大きくなる(画面いっぱいにならないよう、見た目の成長は **Lv7 で打ち止め**。獲得数は Lv10 まで増え続ける) |
| **形** | 1タップの獲得数が **+1** ずつ増える。宝石の形も変わる(下の表) |
| **色** | 虹色レア宝石の出現率が **+4%** ずつ上がる(Lv1 で 4%、Lv10 で 40%) |

| 形Lv | 宝石の形 |
|---|---|
| 1 | 五角形 |
| 2 | 四角形 |
| 3 | 七角形 |
| 4 | ハート型 |
| 5〜10 | 星型 |

### 点数の例

| 大きさLv | 形Lv | ふつうの宝石 | 虹色の宝石 |
|---|---|---|---|
| 1 | 1 | 1 + (1−1) = **1個** | **5個** |
| 1 | 2 | 2 + (1−1) = **2個** | **10個** |
| 3 | 2 | 2 + (3−1) = **4個** | **20個** |
| 10 | 10 | 10 + (10−1) = **19個** | **95個** |

## ファイルの説明

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の**構造**(何がどこにあるか)を書くファイル |
| `style.css` | 画面の**見た目**(色・大きさ・配置)を書くファイル |
| `script.js` | ゲームの**動き**(クリックしたら宝石が増える等)を書くファイル |

どのファイルにも日本語のコメント(`<!-- -->` や `/* */` や `//` で囲まれたメモ)を
たくさん書いてあるので、読みながら少しずつ変更してみてください。

## VS Code での編集のしかた

1. VS Code を開く
2. メニューの「ファイル」→「フォルダーを開く」で、このフォルダーを選ぶ
3. 左側のファイル一覧から編集したいファイルをクリックして開く
4. 保存は `Ctrl + S`(Mac は `Cmd + S`)

### 動かして確認する方法(おすすめ)

VS Code の拡張機能 **Live Server** を入れると便利です。

1. VS Code の左側の四角いアイコン(拡張機能)をクリック
2. 「Live Server」で検索してインストール
3. `index.html` を右クリック →「Open with Live Server」
4. ブラウザが開いてゲームが動きます。**ファイルを保存すると自動で画面が更新される**ので、
   変更した結果がすぐ確認できます

拡張機能を入れなくても、`index.html` をダブルクリックしてブラウザで開くだけでも動きます。

## 宝石を自分の画像に差し替えたいとき

`script.js` のいちばん上に **「★ 画像さしかえコーナー ★」** があります。
画像のファイル名を書くだけで差し替えられます。

1. 画像ファイル(例: `gem.png` や `rainbow.png`)をこのフォルダーに入れる
2. `script.js` の `gemImages` の `null` を `"ファイル名"` に書きかえる:

   ```js
   const gemImages = {
     1: "gem.png",           // 形Lv1(五角形)のかわりにこの画像を使う
     2: null,                // null のままなら SVG の四角形の宝石
     3: null,                // 七角形
     4: null,                // ハート型
     5: null,                // 星型
     rainbow: "rainbow.png", // 虹色のレア宝石のかわりに使う画像
   };
   ```

- `null` のままの形は、今までどおり SVG(`index.html` の `<template>`)で描いた宝石になります
- 画像に差し替えた宝石には、色のランダム変化(hue-rotate)はかかりません。
  画像そのままの色で表示されます(光る影だけ付きます)
- 背景が透明な PNG 画像を使うときれいに見えます
