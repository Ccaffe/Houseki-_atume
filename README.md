# 宝石あつめ 💎

宝石をクリック(タップ)して集めるクリッカーゲームです。

## 遊び方

1. `index.html` をブラウザで開く
2. 画面のあちこちに宝石が2〜3個出現します
3. 宝石をクリック(タップ)すると、キラーン♪という効果音と共に消えて集まります
4. ステータスパネルの各行にある「Lv UP」ボタンを押すと、宝石を払ってその場で強化できます(下の「レベルアップの効果と点数」を見てね)
5. 「せってい」から、集めた宝石の総数などの統計が見られます
6. データはブラウザに自動保存されるので、閉じてもまた続きから遊べます

## レベルアップの効果と点数

強化すると、新しいレベルの宝石が**追加**されます。
古いレベルの宝石も消えずに、**今までのレベルの宝石がぜんぶ混ざって出てきます**。
(例: 形Lv3 なら、五角形・四角形・七角形の宝石が同じ確率でランダムに出る)

出てきた宝石には、それぞれ自分の「形Lv」「大きさLv」「色Lv」があって、
タップしたときの点数はその宝石自身のレベルで決まります:

**1タップで集まる宝石の数 = 形Lv +(大きさLv − 1)+(色Lv − 1)**
(ぜんぶ「タップした宝石自身」のレベル)

| 強化 | レベルが上がると何が起きる? |
|---|---|
| **大きさ** | より大きくて高得点な宝石が出現リストに追加される。見た目は1レベルごとに **+5ピクセル** ずつ少しずつ大きくなる(画面いっぱいにならないよう、見た目の成長は **Lv7 で打ち止め**。点数は Lv10 まで増え続ける) |
| **形** | 新しい形の高得点な宝石が出現リストに追加される(下の表) |
| **色** | 新しい色の高得点な宝石が出現リストに追加される。色は**赤から始まって、色相環をたどって青まで**進む(下の表) |

| 形Lv | 宝石の形 |
|---|---|
| 1 | 五角形 |
| 2 | 四角形 |
| 3 | 七角形 |
| 4 | ハート型 |
| 5〜10 | 星型 |

| 色Lv | 宝石の色(だいたいの目安) |
|---|---|
| 1 | 赤 |
| 2 | オレンジ |
| 3 | 黄色 |
| 4 | 黄緑 |
| 5 | 緑 |
| 6 | 青みの緑 |
| 7 | 青緑 |
| 8 | 水色 |
| 9 | うすい青 |
| 10 | 青 |

(プログラムの中では「色相環」を赤=0度から青=240度まで9等分して進んでいます)

### 点数の例(タップした宝石のレベルで決まる)

| 形Lv | 大きさLv | 色Lv | 集まる数 |
|---|---|---|---|
| 1 | 1 | 1 | 1 + 0 + 0 = **1個** |
| 2 | 1 | 1 | 2 + 0 + 0 = **2個** |
| 2 | 3 | 4 | 2 + 2 + 3 = **7個** |
| 10 | 10 | 10 | 10 + 9 + 9 = **28個** |

つまり、**大きい宝石・めずらしい形・青に近い色ほど高得点**。
たくさん強化したあとは、大きくて青い星型を狙ってタップするのがコツです。

## ファイルの説明

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の**構造**(何がどこにあるか)を書くファイル |
| `style.css` | 画面の**見た目**(色・大きさ・配置)を書くファイル |
| `script.js` | ゲームの**動き**(クリックしたら宝石が増える等)を書くファイル |

どのファイルにも日本語のコメント(`<!-- -->` や `/* */` や `//` で囲まれたメモ)を
たくさん書いてあるので、読みながら少しずつ変更してみてください。

## VS Code での編集のしかた

1. VS Code を開く
2. メニューの「ファイル」→「フォルダーを開く」で、このフォルダーを選ぶ
3. 左側のファイル一覧から編集したいファイルをクリックして開く
4. 保存は `Ctrl + S`(Mac は `Cmd + S`)

### 動かして確認する方法(おすすめ)

VS Code の拡張機能 **Live Server** を入れると便利です。

1. VS Code の左側の四角いアイコン(拡張機能)をクリック
2. 「Live Server」で検索してインストール
3. `index.html` を右クリック →「Open with Live Server」
4. ブラウザが開いてゲームが動きます。**ファイルを保存すると自動で画面が更新される**ので、
   変更した結果がすぐ確認できます

拡張機能を入れなくても、`index.html` をダブルクリックしてブラウザで開くだけでも動きます。

## 宝石を自分の画像に差し替えたいとき

`script.js` のいちばん上に **「★ 画像さしかえコーナー ★」** があります。
画像のファイル名を書くだけで差し替えられます。

1. 画像ファイル(例: `gem.png`)をこのフォルダーに入れる
2. `script.js` の `gemImages` の `null` を `"ファイル名"` に書きかえる:

   ```js
   const gemImages = {
     1: "gem.png", // 形Lv1(五角形)のかわりにこの画像を使う
     2: null,      // null のままなら SVG の四角形の宝石
     3: null,      // 七角形
     4: null,      // ハート型
     5: null,      // 星型
   };
   ```

- `null` のままの形は、今までどおり SVG(`index.html` の `<template>`)で描いた宝石になります
- 画像に差し替えた宝石には、色のランダム変化(hue-rotate)はかかりません。
  画像そのままの色で表示されます(光る影だけ付きます)
- 背景が透明な PNG 画像を使うときれいに見えます

## 強化の項目をふやしたいとき

ステータスパネルは**中だけが縦スクロール**するので、行が何個増えても
レイアウトはくずれません(3行を超えたぶんはスクロールで見られます)。

新しい強化(例:「輝き」)を足すときに触る場所:

1. `index.html` の `.status-rows` の中に、既存の行(`.status-row`)をコピーして1行足す
   (id の `size` の部分を新しい名前に変える)
2. `script.js` の `upgrades` に項目を足して、`updateDisplay()` の中の
   `updateOneUpgrade(...)` とボタンの関連付けのところに1行ずつ追加する
