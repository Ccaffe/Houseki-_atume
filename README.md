# 宝石あつめ 💎

宝石をクリック(タップ)して集めるクリッカーゲームです。

## 遊び方

1. `index.html` をブラウザで開くと、お屋敷の主(おじょうさま)が
   セリフの吹き出しで遊び方を案内してくれます
2. はじめての人は**「はじめてボーナス」**からスタート!
   宝石が画面いっぱいに絶え間なく出てきて、**50個あつめるまで**止まりません
3. そのあとは、宝石が**約2.5秒に1個**ずつ湧いてきて、どんどんたまっていきます。
   タップすると、キラーン♪という効果音と共に消えて集まります
   - 放っておくと**最大100個**(画面いっぱい)までたまるので、一気に集めると爽快!
   - ただし、たまりすぎると**いちばん古い宝石が点滅して消えて**いきます
     (約8秒にひとつ。点滅中にタップすれば救出できる!6個以下なら消えません)
   - 100個まで埋まると湧きはお休みし、80個まで減るとまた湧き始めます
4. ステータスパネルの各行にある「Lv UP」ボタンを押すと、宝石を払ってその場で強化できます(下の「レベルアップの効果と点数」を見てね)
5. **ユーザーレベル5**になると宝箱制度が解禁!まず特典の宝箱 🎁 が出てきて、
   そのあとは ときどき(2〜5分にひとつ)ランダムに出現します。
   開けると **エレガントタイム**! 30秒間、画面いっぱいに宝石が出てきて、
   たくさん集められます(ふつうの宝箱は20秒で消えるので急いでタップ!)
6. 「やかた」には**実績(トロフィー)**があり、達成すると「うけとる」ボタンが出ます。
   押すとごほうびの宝石がもらえて、獲得数のボーナスも増えます
   (受け取り待ちがあると、メニューの「やかた」に赤い **!** が付きます)
7. 「せってい」から、集めた宝石の総数などの統計が見られます
8. データはブラウザに自動保存されるので、閉じてもまた続きから遊べます

### あとから出てくるボタン(最初は隠れています)

ゲームを始めたばかりのときは、下のメニューは **4つ**(あつめる・やかた・ストア・せってい)、
「やかた」の中も **実績だけ**です。遊び進めると、順番に増えていきます。

| でてくるもの | 出る条件 |
|---|---|
| やかたの **宝物庫** タブ | はじめて**お屋敷を継ぐ**(2代目になる) |
| やかたの **図鑑** タブ | 宝物庫で **📖宝石図鑑** を買う |
| メニューの **ストーリー** | **6巡クリア**(6回お屋敷を継いで7代目になる)|

ストーリーは「ぜんぶ遊びきった人へのおまけ」の、のんびりした日常のお話です。
解放のタイミングは `script.js` の `STORY_UNLOCK_GENERATION`(いまは 7 = 7代目)で変えられます。

エレガントタイムの長さや宝箱の出やすさは、`script.js` の
「宝箱とフィーバータイムの設定」(`FEVER_SECONDS` など)の数字で変えられます。
チュートリアルのセリフは `script.js` の**「★ セリフ編集コーナー ★」**に
まとめてあるので、文章を書きかえるだけで変えられます。
文字のフォントは上品な明朝体「しっぽり明朝」(Google Fonts)を使っています。

## レベルアップの効果と点数

強化すると、新しいレベルの宝石が**追加**されます。
古いレベルの宝石も消えずに、**今までのレベルの宝石がぜんぶ混ざって出てきます**。
(例: 形Lv3 なら、五角形・四角形・七角形の宝石が同じ確率でランダムに出る)

出てきた宝石には、それぞれ自分の「形Lv」「大きさLv」「色Lv」があって、
タップしたときの点数はその宝石自身のレベルで決まります:

**1タップで集まる宝石の数 = 形Lv +(大きさLv − 1)+(色Lv − 1)**
(ぜんぶ「タップした宝石自身」のレベル)

### 強化の解放順(インクリメンタル!)

強化は最初は**「形」だけ**使えます。前の強化を **Lv10** まで上げると、
次の強化が解放されていきます(MAX まで上げなくてOK):

**形 → 色 → 大きさ → 秒数 → 範囲**

まだ解放されていない強化は、パネルで薄く表示されて 🔒 が付いています。
レベルの上限は **Lv30**。Lv10 で次が解放されたあとも、
その先の Lv30 まで育て続けられます(点数はレベルぶんずっと増えます)。

| 強化 | レベルが上がると何が起きる? |
|---|---|
| **形** | 新しい形の高得点な宝石が出現リストに追加される(下の表) |
| **色** | 新しい色の高得点な宝石が出現リストに追加される。色は**赤から始まって、色相環をたどって青まで**進む(下の表) |
| **大きさ** | より大きくて高得点な宝石が出現リストに追加される。見た目は段階が進むごとに **+4ピクセル** ずつ大きくなる(10段階目で +36ピクセル。点数は Lv30 まで増え続ける) |
| **秒数** | 宝石が湧いてくる間隔が1レベルごとに **0.07秒** 短くなる(ふだん2.5秒 → Lv30で0.47秒。画面が埋まる速さが5倍以上に!点数には影響しない) |
| **範囲** | 1タップで**まわりの宝石もまとめて集められる**ようになる。まとめて取れる半径が1レベルごとに **+6ピクセル** 広がる(Lv1 は 0 = タップした1個だけ。Lv30 なら半径174ピクセルで画面のかなりの範囲を一掃!)。集めた範囲には金色の波紋が広がる |

### 見た目が変わるレベル(デザイン段階)

レベルが1上がるたびに見た目が変わるとネタ切れになってしまうので、
**節目のレベルに届いたときだけ**見た目が変わります。段階は全部で **10種類**:

**Lv1・2・3・4・5・6・7・8 → Lv20 → Lv30**

(例: 形Lv8 で「ひし形」になったあとは、Lv19 まで見た目は同じ。
Lv20 で「王冠型」、Lv30 で「花型」が仲間入り!)

| 形Lv | 宝石の形 |
|---|---|
| 1 | 五角形 |
| 2 | 四角形 |
| 3 | 七角形 |
| 4 | ハート型 |
| 5 | 星型 |
| 6 | 六角形 |
| 7 | しずく型 |
| 8〜19 | ひし形 |
| 20〜29 | 王冠型 |
| 30 | 花型 |

| 色の段階 | 宝石の色(だいたいの目安) |
|---|---|
| 1 | 赤 |
| 2 | オレンジ |
| 3 | 黄色 |
| 4 | 黄緑 |
| 5 | 緑 |
| 6 | 青みの緑 |
| 7 | 青緑 |
| 8 | 水色 |
| 9 | うすい青 |
| 10 | 青 |

(色も形と同じ節目で変わります。プログラムの中では「色相環」を
赤=0度から青=240度まで9等分して進んでいます)

### 点数の例(タップした宝石のレベルで決まる)

| 形Lv | 大きさLv | 色Lv | 集まる数 |
|---|---|---|---|
| 1 | 1 | 1 | 1 + 0 + 0 = **1個** |
| 2 | 1 | 1 | 2 + 0 + 0 = **2個** |
| 2 | 3 | 4 | 2 + 2 + 3 = **7個** |
| 10 | 10 | 10 | 10 + 9 + 9 = **28個** |
| 30 | 30 | 30 | 30 + 29 + 29 = **88個** |

つまり、**大きい宝石・めずらしい形・青に近い色ほど高得点**。
たくさん強化したあとは、大きくて青い花型を狙ってタップするのがコツです。

## ファイルの説明

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の**構造**(何がどこにあるか)を書くファイル |
| `style.css` | 画面の**見た目**(色・大きさ・配置)を書くファイル |
| `script.js` | ゲームの**動き**(クリックしたら宝石が増える等)を書くファイル |

どのファイルにも日本語のコメント(`<!-- -->` や `/* */` や `//` で囲まれたメモ)を
たくさん書いてあるので、読みながら少しずつ変更してみてください。

## 宝石を自分のデザインに差し替えたいとき

宝石の見た目は **10種類** あり、2つのやり方で差し替えられます。

### A. 自分で描いた絵(png など)を使う

1. 絵のファイル(例: `gem.png`)をこのフォルダーに入れる
2. `script.js` のいちばん上の **「★ 宝石デザインさしかえコーナー ★」** で、
   差し替えたい段階の `null` を `"ファイル名"` に書きかえる:

   ```js
   const gemImages = {
     1:  "gem.png", // 五角形   (形Lv1〜)のかわりにこの絵を使う
     2:  null,      // 四角形   (形Lv2〜)…null なら下のSVGの宝石
     3:  null,      // 七角形   (形Lv3〜)
     4:  null,      // ハート型 (形Lv4〜)
     5:  null,      // 星型     (形Lv5〜)
     6:  null,      // 六角形   (形Lv6〜)
     7:  null,      // しずく型 (形Lv7〜)
     8:  null,      // ひし形   (形Lv8〜)
     9:  null,      // 王冠型   (形Lv20〜)
     10: null,      // 花型     (形Lv30)
   };
   ```

- 背景が透明な PNG を使うときれいに見えます
- 絵に差し替えた宝石には色のランダム変化(hue-rotate)はかからず、
  絵そのままの色で表示されます(光る影だけ付きます)

### B. SVG(図形)の形そのものを描きかえる

`index.html` の `<template id="gem-template-1">` 〜 `-10` が宝石の型紙です。
中の `<svg>` を書きかえると、その段階の宝石の形が変わります。

- `viewBox="0 0 200 200"` の中に、200×200 のマス目で図形を描きます
- 外側は `fill="url(#gemOutside)"`、内側は `fill="url(#gemInside)"` と書くと、
  宝石らしいグラデーションと、色レベルによる色変化が自動で付きます
- 段階を増やしたいときは、`script.js` の `DESIGN_STAGE_LEVELS` に
  レベルを足して、同じ数だけ型紙(`gem-template-11` など)を用意します

## ストーリー(会話画面)の書き方・ふやし方

メニューの「ストーリー」は、**6巡クリア(7代目になる)まで隠れています**。
解放されると、お話の一覧が出ます。
**お話をタップすると、フェードで暗転**して画面が切り替わり、
**会話画面(ADV画面)**がはじまります。

会話画面は「背景の絵 + キャラクターの絵 + メッセージウィンドウ」の3枚重ね。
**画面のどこかをタップすると次のセリフに進みます**
(文字が出ている途中でタップすると、一気に全部表示されます)。
右上の「✕」を押すと、途中でも一覧にもどれます。

1話目は最初から読めて、2話目からは **宝石(ダイヤ)100個** で順番に解放します
(必要な数は `script.js` の `STORY_COST` で変えられます)。

### 絵(背景・キャラクター)を差し替える

`script.js` の上のほうにある **「★ ストーリーの絵さしかえコーナー ★」** で、
`file: null` の `null` を `"ファイル名"` に書きかえるだけです。

1. 絵のファイル(png や jpg)を、このフォルダーに入れる
2. 下のように書きかえて保存する
3. ページを開きなおす

```js
// ▼ 背景の絵(お話の「舞台」)
const storyBackgrounds = {
  forest:  { name: "森",         file: "forest.png" }, // ← ここを書きかえた!
  mansion: { name: "森のお屋敷", file: null },
  hall:    { name: "お屋敷の中", file: null },
};

// ▼ キャラクターの絵(画面のまん中に立つ人)
const storyCharacters = {
  ojosama: { name: "おじょうさま", file: null },
};
```

- `null` のままのところは、**仮の絵**(CSSで描いた森・点線のシルエット)が出ます。
  仮のあいだは、画面の左上に「仮の背景:森」と出るので、どの絵を入れる場所か分かります。
- `name:` は仮の絵に表示される名前で、しゃべる人の**名前の札**にも使われます。
- 新しい舞台やキャラクターを足したいときは、行をコピーして増やすだけです。
- 絵のおすすめサイズ … 背景は縦長(例: 800×1400)、キャラクターは背景が透明な png。

### お話の中身を書く

`script.js` の **「★ ストーリー編集コーナー ★」** に書きます。
`{ ... }` のかたまり1つが、メッセージウィンドウ1回ぶんです。

```js
const stories = [
  {
    title: "森のお屋敷",        // ← 一覧に出るタイトル
    scenes: [
      // 地の文(キャラクターを出さない)
      { bg: "forest", chara: null, text: `深い森の、そのまた奥。
地図にものっていない小道の先に、そのお屋敷はあるという。` },

      // キャラクターがしゃべる(名前の札が自動で出る)
      { bg: "hall", chara: "ojosama", text: `あら。……お客様だわ。` },
    ],
  },
  // ↓このかたまりをコピーして増やせば、お話が増える
];
```

| 書くもの | 意味 |
| --- | --- |
| `bg` | 背景の名前(`storyBackgrounds` に書いた名前) |
| `chara` | キャラクターの名前(`storyCharacters` に書いた名前)。`null` で地の文 |
| `text` | セリフ。バッククォート( ` )で囲むと、改行もそのまま表示される |
| `name` | (省略OK)名前の札を、わざと別の名前にしたいとき |

文字が1文字ずつ出る速さは `script.js` の `TYPE_SPEED`(数字が小さいほど速い)、
暗転の長さは `FADE_TIME` で変えられます
(`FADE_TIME` を変えるときは `style.css` の `.fade-screen` の `0.4s` も同じ数字にしてね)。

## ストアの商品のふやし方

メニューの「ストア」からストア画面に行けます。
いまは **仮オープン** で、購入ボタンを押しても「準備中」のお知らせが出るだけです
(実際のお支払いは発生しません。本物の課金には Stripe などの決済サービスとの
連携が必要になるので、公開の形が決まったら組み込みます)。

商品は `script.js` の **「★ ストア商品コーナー ★」** に書くだけで増やせます:

```js
const products = [
  {
    icon: "💝",                 // 商品の絵(絵文字)
    name: "製作者支援",          // 商品名
    description: "説明文…",     // 説明
    price: 500,                 // お値段(日本円)
  },
  // ↓このかたまりをコピーして増やす
];
```

## 強化の項目をふやしたいとき

ステータスパネルは**中だけが縦スクロール**するので、行が何個増えても
レイアウトはくずれません(3行を超えたぶんはスクロールで見られます)。

新しい強化(例:「輝き」)を足すときに触る場所:

1. `index.html` の `.status-rows` の中に、既存の行(`.status-row`)をコピーして1行足す
   (id の `size` の部分を新しい名前に変える)
2. `script.js` の `upgrades` に項目を足して、`UPGRADE_ORDER`(解放される順番)、
   `updateDisplay()` の中の `updateOneUpgrade(...)`、
   ボタンの関連付けのところに1行ずつ追加する

## お屋敷を継ぐ(プレステージ)と「やかた」

強化を育てきっても終わらないように、**周回(しゅうかい)**の仕組みがあります。

### お屋敷を継ぐ

いま何代目か・持っている家宝の数は、**ヘッダーには出さず**に
「やかた」の宝物庫の右上と、せっていの統計・実績で見られます
(ヘッダーが長くなって折り返してしまうのを防ぐため)。

| 項目 | 内容 |
|---|---|
| 継げる条件 | 5つの強化が **ぜんぶ Lv10 以上**(`PRESTIGE_NEED_LEVEL`) |
| もらえる家宝 | `User Lv ÷ 10` を切り捨てた数(`HEIRLOOM_PER_USER_LEVEL`)<br>全部Lv10(User Lv46)→ **4つ** / 全部Lv30(User Lv146)→ **14こ** |
| 消えるもの | いま持っている宝石・5つの強化レベル(Lv1にもどる) |
| のこるもの | 家宝・宝物庫で買った品・図鑑・実績・ストーリー・統計・チュートリアル済み |

条件を満たすと、ステータスパネルのいちばん下の **「お屋敷を継ぐ」** の行が
金色に光って押せるようになります(それまでは 🔒)。

### やかた画面(メニューの「やかた」)

上のタブで3つの部屋を切り替えます。

#### ① 宝物庫(ほうもつこ)

家宝を払って買う、**ずっと消えない永久アップグレード**のお店です。

| 品物 | 家宝 | 効果 |
|---|---|---|
| 👁️ 目利き | 2 | 宝石の獲得数 **+25%** |
| 🔔 使用人を雇う | 3 | 使用人が宝石を**自動で拾ってくれる** |
| ⛲ 宝石の泉 | 4 | 宝石の湧く間隔が **15%短く** |
| 📦 玄関の宝石箱 | 5 | 継いだあと **宝石500個** を持ってスタート |
| 📖 宝石図鑑 | 5 | **図鑑が開く**(1種類につき獲得数 +1%) |
| 🧹 使用人の手際 | 6 | 使用人の拾う速さが **2倍**(先に「使用人を雇う」が必要) |
| 🕯️ 優雅な時間 | 7 | エレガントタイムが **45秒**(+15秒) |
| 🗝️ 常連の商人 | 8 | 宝箱の出る間隔が **半分** |
| 💰 値切り上手 | 10 | 強化(Lv UP)のお値段が **2割引** |

品物を増やしたいときは、`script.js` の **「★ 宝物庫コーナー ★」** に
かたまりをコピーして足すだけです:

```js
const treasureItems = [
  {
    id: "eye",              // 見分けるための名前(英語。ほかとかぶらないように)
    icon: "👁️",             // 一覧に出る絵文字
    name: "目利き",          // 品物の名前
    cost: 2,                // お値段(家宝の数)
    needs: null,            // 先に買っておく品の id(いらなければ null)
    description: "説明文…",
  },
  // ↓このかたまりをコピーして増やす
];
```

※ **効果そのもの**は `script.js` の中で `hasTreasure("id")` を使って分けています。
新しい効果を足すときは、効かせたい場所に
`if (hasTreasure("新しいid")) { … }` を1行足してください。
効果の強さの数字は `EYE_BONUS` などの定数にまとめてあります。

#### ② 宝石図鑑(形10 × 色10 = 100種類)

集めた宝石の「形のだんかい」と「色のだんかい」の組み合わせが記録されます。
**1種類につき獲得数が +1%**(ぜんぶ埋めると +100%!)。
図鑑じたいは宝物庫の「宝石図鑑」を買うと開きますが、
**記録は最初から始まっている**ので、買った瞬間にどっと埋まります。

#### ③ 実績(トロフィー)

「宝石を100個あつめる」などのお題です。条件を満たすと **「うけとる」ボタン**が出て、
押すとごほうびの宝石がもらえます。受け取った実績 **1つにつき獲得数が +2%**。
(受け取り待ちがあるあいだは、メニューの「やかた」と実績タブに赤い **!** が付きます)
実績は `script.js` の **「★ 実績コーナー ★」** に書いてあり、
`check` のところに条件を書くだけで増やせます:

```js
{ id: "first100", icon: "🌱", name: "はじめの一歩",
  detail: "宝石を100個あつめる", reward: 50,
  check: function () { return totalGems >= 100; } },  // ← ここが条件
```

## ときどき起こること(ランダムイベント)

User Lv5 から、1分半〜3分に1回くらい、こんなことが起こります。

- 🐈‍⬛ **黒猫** … お屋敷に住みついた気まぐれな黒猫。画面にある宝石を5個くわえて、
  むらさきの光をまといながら、音もなく夜の闇を横切っていきます。
  消えてしまう前にタップして声をかけると、**宝石を置いていってくれます**
  (持っている宝石は減りません)
- 🧺 **行商人** … しばらく立ち止まっている。タップすると宝石をどっさりゆずってくれる

設定は `EVENT_WAIT_MIN` / `EVENT_WAIT_MAX` / `CAT_STEAL` / `CAT_LIFETIME` の定数で変えられます。
